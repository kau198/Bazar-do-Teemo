Como instalar

  1. Toque em Baixar APK de teste no seu Android.
  2. Aguarde o download do arquivo baazar-do-teemo.apk.
  3. Abra baazar-do-teemo.apk no Android. Autorize a instalação por esse navegador ou gerenciador de arquivos apenas se você reconhecer este download.
  4. Abra o app: ele já vem conectado à loja. Se você configurou outro endereço anteriormente, toque em Servidor e use https://bazar-do-teemo.onrender.com.

O download é direto, sem conta GitHub e sem precisar extrair arquivos. Ver outras compilações no GitHub ↗

Esta versão é para avaliação do projeto. Pagamento, frete e envio de pedidos ainda não estão disponíveis. O APK não é compatível com iPhone; no iPhone, você pode usar o site no navegador.

Se já instalou um APK de teste anterior e o Android recusar a atualização, desinstale a versão antiga antes de instalar esta. Isso apaga a sacola e os favoritos salvos no aplicativo; sua conta no site permanece.
